# История изменений

Все заметные изменения проекта описаны здесь. Формат —
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), версии —
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] - 2026-11-23

### Добавлено

- `node scripts/link.mjs --check '<ссылка>' [--expect <файл>]` распаковывает
  ссылку, считает узлы и потоки и сверяет текст с файлом. Вставленный или
  потерянный символ даёт `битая ссылка` и код 1 вместо молчаливого демо
  Wages/Budget на сайте.
- `link.mjs` печатает отпечаток payload в stderr: длину и 8 символов sha256.
- `buildLink` сверяет свой вывод с исходным текстом и падает при расхождении.

### Изменено

- `SKILL.md`: ссылку нельзя пересказывать — только копия вывода скрипта плюс
  отпечаток; при «не той» диаграмме — `--check`.
- `README`: обновление и удаление скилла разведены по разным блокам; удаление
  защищено `${SKILL_DIR:?}` и `--`.

## [0.2.6] - 2026-11-23

### Добавлено

- Проверка безопасности в CI: `.github/workflows/security.yml` — тесты,
  CodeQL (`security-extended`) и gitleaks по всей истории. Экшены закреплены
  коммит-SHA, бинарник gitleaks — по sha256; запуск на push, pull request, по
  расписанию и вручную.

### Исправлено

- Гонки файловой системы в кэше и локальном сервере: чтение идёт через
  дескриптор с `O_NOFOLLOW`, запись — в `*.part` с атомарным `renameSync`.
  Закрывает два алерта CodeQL `js/file-system-race`.

## [0.2.5] - 2026-11-23

### Безопасность

- `link.mjs` сверяет sha256 вендорного `lz-string` до исполнения. Файл заменён
  на публичный артефакт 1.4.4, версия и хэш записаны в `NOTICE`, а совпадение
  вывода сжатия с копией сайта закреплено эталоном
  `tests/fixtures/pl-1800.payload.txt`.
- Кэш ассетов не читает и не пишет через симлинки, получает права `0700`, а
  ответ больше 2 МБ отклоняется до сверки хэша.
- `local.mjs --check` больше не скачивает: проверяет кэш офлайн и выходит с
  кодом 2, если он неполный.

### Исправлено

- Валидатор обходит граф итеративно: цепочка на 20 000 узлов больше не роняет
  процесс переполнением стека.
- `layout.mjs` отклоняет нечисловой `--label-size` и сообщает о цикле без
  трассировки стека.
- `references/layout.md` перечисляет `layout order exact` среди управляемых
  настроек.

## [0.2.4] - 2026-11-23

### Исправлено

- Порядок стоков последней колонки: крупные выше, мелкие ниже, плюс
  `layout order exact`. «Налоги» больше не задевают «Амортизацию».
- Высота возвращена к 850 px: увеличение из 0.2.3 оказалось лишним.

## [0.2.3] - 2026-11-23

### Исправлено

- Высота полотна учитывает вертикальные поля полупрозрачной рамки подписи
  (`top` + `bot`, около `0.3 · labelSize`). Рамка «налоги» больше не задевает
  «амортизацию»; русский P&L — 900 px по высоте вместо 850, ширина осталась
  850.

## [0.2.2] - 2026-11-23

### Добавлено

- В README, рядом с картинкой, добавлен текст запроса, из которого получилась
  диаграмма.

## [0.2.1] - 2026-11-23

- Описание репозитория уточнено под несколько агентов.

## [0.2.0] - 2026-11-23

### Добавлено

- Соответствие открытому стандарту Agent Skills: `name: sankeymatic`,
  `license: MIT`, `compatibility`. Скилл можно установить в Claude Code,
  OpenAI Codex и VS Code Copilot по их каталогам скиллов.
- Раздел README «Без OpenCode» с оговоркой, что скилл проверен только в
  OpenCode.
- `local.mjs --open` выбирает `open` / `xdg-open` / `start` по платформе.
- Тест `scripts/skill.test.mjs` проверяет frontmatter по стандарту.

## [0.1.4] - 2026-11-23

### Добавлено

- Пример готовой диаграммы в README: `docs/images/result.png`.

## [0.1.3] - 2026-11-23

### Исправлено

- Подписи больше не налезают по вертикали: высота полотна считается по
  фактическому зазору между узлами (`node h`, `node spacing`) и высоте подписи,
  а не по числу узлов. Русский P&L — 850 px вместо 600.

## [0.1.2] - 2026-11-23

### Исправлено

- Полотно было слишком широким: формула из 0.1.1 резервировала ширину внешних
  подписей дважды. Теперь ширина считается по зазорам между стадиями:
  `поля + стадии * node_w + (стадии − 1) * (ширина подписи + 10)`.
  Русский P&L — 850 px вместо 1400 (−39 %), английский — 700 вместо 1150.

## [0.1.1] - 2026-11-23

### Исправлено

- Длинные подписи больше не налезают на соседние колонки: `scripts/layout.mjs`
  переносит имена по словам и подбирает `size w` / `size h` под длину подписей
  и число стадий.
- Сумма больше не оказывается в одной строке с именем: скилл явно пишет
  `labelvalue position below`, потому что сайт при открытии ссылки подставляет
  `labelvalue position after`.
- Ссылка и вставка в поле Inputs теперь выглядят одинаково:
  `labelposition scheme auto` и `labels relativesize 100` задаются явно.

### Добавлено

- `scripts/layout.mjs` и `references/layout.md` с формулами полотна.
- Golden-кейс с русскими подписями `tests/fixtures/pl-1800-ru.txt`.

## [0.1.0] - 2026-11-23

### Добавлено

- Скилл для OpenCode, превращающий текст в исходник SankeyMATIC: четыре вопроса
  с дефолтами (размер меток 18, высота узлов 20, расстояние 30, тема Categories),
  необязательный вопрос про единицы измерения и правила моделирования
  сбалансированных потоков.
- `scripts/validate.mjs`: синтаксис, список допустимых настроек, неположительные
  суммы, циклы, потоки узла в себя и предупреждения о дисбалансе. Коды выхода
  0/1, флаги `--strict`, `--json`.
- `scripts/link.mjs`: ссылки `?i=` с той же кодировкой, что использует сайт.
- `scripts/local.mjs` и `scripts/assets.mjs`: локальный предпросмотр на
  `127.0.0.1` с закреплёнными файлами и проверкой контрольных сумм; в странице
  не остаётся CDN.
- Golden-фикстура `tests/fixtures/pl-1800.*`: 10 потоков, 11 узлов,
  0 дисбалансов.
- Документация: README, справочники по моделированию, синтаксису и палитрам,
  AGENTS.md, NOTICE с атрибуцией ISC/MIT.
