# Темы и палитры

SankeyMATIC назначает цвет узла из выбранной темы в порядке первого появления
узлов в исходнике. Первый цвет темы достаётся первому новому узлу, второй —
второму и так далее; после последнего цвета список продолжается с начала. Чтобы
сдвинуть начало, есть `themeoffset_*` в `syntax.md`.

Темы — это категориальные схемы d3, которые использует сайт
(`build/constants.js`, закреплённая сборка `nowthis/sankeymatic@a6d8053`).

## Как поток получает цвет

При `flow inheritfrom source` (именно это пишет скилл) каждый поток берёт цвет
своего источника с прозрачностью `flow opacity 0.45`. На белом фоне это
выглядит как более светлая, смешанная версия цвета узла. Два других
автоматических варианта — `flow inheritfrom target` и
`flow inheritfrom outside-in`.

## Когда нужны явные цвета

Только когда пользователь просит конкретные цвета. Тогда добавляются строки
узлов и цвета потоков:

```
:Revenue #1f77b4
:Gross Profit #2ca02c
Revenue [800] Cost of Sales #d62728
```

Явные цвета перекрывают тему для названных узлов и потоков, остальное остаётся
в теме. Не смешивайте тему с ручными цветами, если пользователь об этом не
просил.
