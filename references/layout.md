# Полотно и подписи

`scripts/layout.mjs` — обязательный постпроцессор: он превращает черновой
исходник в файл, который одинаково выглядит и по ссылке, и при вставке в поле
Inputs.

```sh
node scripts/layout.mjs <файл> --in-place
```

## Зачем он нужен

1. **Размер полотна.** По умолчанию SankeyMATIC рисует на 600 × 600. Пять
   колонок делят ~560 px на четыре зазора — по ~140 px. Русское название
   «операционная прибыль» при 18 px занимает около 200 px и налезает на
   соседнюю колонку.
2. **Позиция суммы.** При открытии ссылки сайт вызывает
   `setUpNewInputs()`, который **всегда** добавляет `settingsToBackfill`:
   `labelvalue position after`, `labelposition scheme per_stage`,
   `labels relativesize 100`, `magnify 100`. Если в исходнике нет явной
   позиции, побеждает `after` — сумма оказывается в одной строке с именем.
   В поле Inputs дефолт другой. Явные настройки убирают эту разницу.
3. **Переносы.** Сайт умеет `\n` внутри имени, но сам не переносит. Длинное
   имя остаётся одной строкой.

## Что скрипт пишет

Управляемые настройки (старые значения удаляются и заменяются):

```
labelvalue position below
labelposition scheme auto
labels relativesize 100
size w <ширина>
size h <высота>
```

Остальные настройки — `labelname size`, `node h`, `node spacing`, `node theme`,
`flow inheritfrom source`, `flow opacity`, единицы измерения — сохраняются как
есть.

## Формулы

- Лимит строки: `round(200 / (labelSize * 0.56))`, но не меньше 10 символов.
  При 18 px это 20 символов, при 24 px — 15.
- Ширина: `поля + 2 * ширина подписи + (стадии − 1) * (node_w + ширина подписи + 20) + node_w + 5 * (стадии − 1)`,
  округление вверх до 50, зажим 600…1600.
- Высота: `поля + max по колонкам [узлов * (строк * labelSize * 1.3 + 34)]`,
  округление вверх до 50, зажим 600…1200. Высота растёт, только если в колонке
  много узлов с многострочными подписями.
- `0.56` — средняя ширина символа sans-serif в долях кегля; запас 20 px и
  внешние подписи учтены отдельно.

## Правила переноса

- Режется по пробелам, слово целиком не рвётся.
- Уже существующий `\n` считается жёстким переносом; повторный запуск ничего
  не меняет (идемпотентность).
- Если одно слово длиннее лимита, оно остаётся в строке целиком: лучше
  переполнение, чем разорванное слово.

## Если ширина упёрлась в 1600

Значит подписи слишком длинные для выбранного кегля. Варианты, в порядке
предпочтения:

1. сократить названия узлов, сохранив смысл;
2. уменьшить `labelname size` (например, 16);
3. скрыть суммы: `labelvalue appears n` — подписи станут короче.

Не увеличивайте `maxWidth` вслепую: на экране такая диаграмма перестаёт
читаться.
